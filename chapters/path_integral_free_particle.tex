In this chapter, we solve for the theory of a free particle using the path integral formulation. 

\begin{align}
(x_bt_b|x_at_a) &= \int_{x(t_a)=x_a}^{x(t_b)=x_b}\mathcal{D}'x \int \frac{\mathcal{D}p}{2\pi\hbar} \exp \left [\frac{i}{\hbar} \int_{t_a}^{t_b} dt\left ( p \dot{x} - \frac{p^2}{2M} \right )\right]
\end{align}
%The pure configuration form (\textcolor{red}{TODO: How does this work?}) reads
We can rewrite this path integral to only be in terms of position $x$ and not in terms of momentum $p$ as well
\begin{align}
    (x_bt_b|x_at_a) &= \int_{x(t_a)=x_a}^{x(t_b)=x_b} \mathcal{D}x\exp \left [ \frac{i}{\hbar} \int_{t_a}^{t_b} dt\frac{M}{2}\dot{x}^2\right]
\end{align}
We use the Feynman path integral formula %(\textcolor{red}{TODO: Add the derivation from Kleinert to an earlier chapter.}
\begin{align}
    (x_bt_b|x_at_a) &\approx \prod_{i=1}^N \left [ \int_{-\infty}^\infty dx_n \right] \prod_{n=1}^{N+1} \left [ \int_{-\infty}^\infty \frac{dp_n}{2\pi\hbar} \right] \exp \left( \frac{i}{\hbar} \mathcal{A}^N\right)
\end{align}
where we define the time-sliced action
\begin{align}
\mathcal{A}^N = \sum_{n=1}^{N+1} [p_n(x_n-x_{n-1}) - \epsilon H(p_n,x_n, t_n)]
\end{align}
In our case, note that $V=0$ since we are solving for a free particle, so note that the time-sliced action becomes
\begin{align}
\mathcal{A}^N = \sum_{n=1}^{N+1} \left [ p_n(x_n - x_{n-1}) - \epsilon \frac{p_n^2}{2M} \right ]
\end{align}
