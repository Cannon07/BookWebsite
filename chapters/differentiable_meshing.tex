Many classical numerical methods rely on the construction of an explicit mesh. The marching cubes algorithm, commonly used to construct such meshes, is not natively differentiable. Recent work has revealed how to use deep signed distance functions to create a differentiable approximation to the marching cubes method that can be used to create differentiable meshes \cite{remelli2020meshsdf}, \cite{liu2020general}..

\section{The Marching Cubes Algorithm}

The Marching cubes method from computer graphics provides a way to extract a mesh from a provided 3D voxel dataset. The mesh is mathematically represented by

\begin{align}
\mathcal{M} &= (V, F)
\end{align}
where $V$ is the set of vertices
\begin{align}
V &= \{v_1, v_2, \dotsc \}
\end{align}
and $F$ represents the set of facets.

\section{Deep Signed Distance Functions}
A signed distance function is a function
\begin{align}
s: \mathbb{R}^3 \to \mathbb{R}
\end{align}
defined as
\begin{align}
s(x) &= \begin{cases}
d(x, S) & x \textrm{ outside } S \\
-d(x, S) & x \textrm{ inside } S
\end{cases}
\end{align}
