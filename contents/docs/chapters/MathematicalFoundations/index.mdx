# Appendix: Mathematical Foundations 

This part provides a brief introduction to a variety of different
mathematical topics. If you're working through this book for the first
time, you may prefer to skim sections in this part, and then come back
and refer to sections as you encounter the mathematics in later
chapters.

Each chapter has a number of associated exercises. If you're new to a
topic, work through the exercises to gain some practice with the
concept. The only way to internalize mathematics is practice. If you're
new to formal mathematics, don't worry about the formalism; instead, try
to build intuition. You may find yourself coming back to this part
multiple times as you work your way through the rest of the book.
