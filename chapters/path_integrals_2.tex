In the last chapter we studied the structure of a path integral for a general abstract Hamiltonian. In this chapter, we assume that the Hamiltonian has concrete form
\begin{align}
    H &= \frac{P^2}{2m} + V(X)
\end{align}
Recall the Baker-Campbell Hausdorff Formula
\begin{align}
    e^{A}e^{B} &= e^{A + B + \frac{1}{2}[A, B]+\dotsc}
\end{align}

We can write the time evolution operator for an infinitesimal time $\varepsilon$ as
\begin{align}
    U &= \exp \Bigg [ -\frac{i\varepsilon}{\hbar} (P^2/2m + V(X)) \Bigg ]
\end{align}
Note that then
\begin{align}
    \exp \Bigg[ -\frac{i\varepsilon}{2m\hbar} P^2 \Bigg ] \cdot \exp \Bigg[ -\frac{i\varepsilon}{\hbar} V(X) \Bigg ]  &= 
    \exp \Bigg [ -\frac{i\varepsilon}{2m\hbar}P^2 - \frac{i\varepsilon}{\hbar}V(X) + \frac{-\varepsilon^2}{2m\hbar^2} [P^2, V(X)] + \dotsc \Bigg ]
\end{align}
