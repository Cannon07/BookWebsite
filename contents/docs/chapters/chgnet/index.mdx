# CGHNet: A MLIP Potential Model 

------------------------------------------------------------------------

**Difficulty Level:** **



------------------------------------------------------------------------

Machine learned interatomic potentials are new class of technology.

![MLIP
Schematic](figures/Differentiable Physics/Neural Potentials/chgnet/mlip.png)\

Most MLIPs only describe a single system. Can we make a MLIP that
describes valence states and electrons? Can we reuse model and data
between systems? Can we create a pretrained foundation model?

## Ions

Ions with different valences often have very different geometries.

![Different ions have very different
geometries.](figures/Differentiable Physics/Neural Potentials/chgnet/ion_geometry.png)\

DFT uses electron density. Other formulations use magnetic moments
(magmoms). Can we incorporate magmoms into MLIPs?

A crystal graph is a common representation of a periodic potential. We
create a bond graph that contains 3-body interactions and angular
information.

![Bonds and Atoms are expanded using RBFs and Fourier
Expansions.](figures/Differentiable Physics/Neural Potentials/chgnet/expansions.png)\

## Crystal Hamiltonian Graph Neural Network (CHGNet)

![CHGNets represent charges as magnetic
moments.](figures/Differentiable Physics/Neural Potentials/chgnet/chgnet_schematic.png)\

The model (CHGNet, pronounced ChargeNet) was trained on materials
project data. Also trained on the MPtrj (MP trajectory) dataset.

The model was tested on MatBench Discovery to discovery stable crystals.
CHGNet does well.
