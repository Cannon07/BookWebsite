# Physical Algorithms 

Physicists and computer scientists have invented many algorithms to
model physical systems. In this Part, we review core physical algorithms
that enable effective simulation of physical systems. The algorithms
that you will learn will motivate the design of the differentiable
programs you will encounter in the next Part.
